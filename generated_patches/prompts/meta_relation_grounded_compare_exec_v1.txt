If the question is not a comparison question, ignore this workflow completely and answer normally.

Follow this grounded comparison workflow before answering comparison questions.
Use this workflow when the question matches cues such as: greater, fewer, more, less, left of, right of, behind, in front of, yes/no.
Do not use this workflow when the question instead looks like: total volume, capacity, measure, reading, what is the total, highest amount.

1. Identify set A and set B exactly as named in the question.
2. List the candidate objects for set A with visible evidence for each object.
3. List the candidate objects for set B with visible evidence for each object.
4. Count both grounded sets explicitly.
5. Restate the exact comparison relation being asked and check whether it is true before answering Yes or No.
Only after these steps are completed should you produce the final answer.
