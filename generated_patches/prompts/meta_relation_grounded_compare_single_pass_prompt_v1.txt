Apply this workflow only to explicit comparison questions asking whether one set is greater, fewer, more, less, left of, right of, behind, or in front of another set. Identify set A and set B exactly as named in the question. Make one grounded pass: write one object list for set A and one object list for set B with visible evidence for each object. Do not recursively re-zoom, re-count, or restart the comparison after the first grounded pass. If some evidence remains ambiguous after the single pass, stop and answer from the best grounded counts already obtained. Do not use this workflow for measurement-reading or subtract/remove counting questions.
